# Мой Скриншот для Windows

Первая версия для Windows 10 (версия 2004 и новее) и Windows 11. Выберите архив для своей архитектуры (x64 или ARM64), распакуйте его в папку, где хотите хранить приложение, и откройте `MyScreenshot.exe`. Сборка включает .NET Desktop Runtime. Приложение работает в области уведомлений рядом с часами.

- **Ctrl+Shift+A** открывает захват области на мониторе под указателем. Щёлкните по подсвеченному окну или выделите нужную область мышью. Границы и углы можно менять после выделения. **Alt** + перетаскивание перемещает рамку.
- Для разметки доступны стрелка, карандаш, линия, прямоугольник, эллипс, текст и ластик. **Ctrl+C** сохраняет снимок и копирует его в буфер обмена. **Esc** закрывает редактор.
- В меню значка доступны снимок всего экрана, запись области и запись всего экрана. Выберите **Остановить запись**, чтобы сохранить MP4. Запись идёт без звука и использует Windows Media Foundation. Для Windows N требуется пакет Media Feature Pack.
- Нажмите на миниатюру, чтобы открыть файл и показать его в Проводнике. Перетащите миниатюру в чат или другое приложение, чтобы прикрепить файл. Короткое движение вправо с отпусканием скрывает миниатюру.
- Снимки и записи сохраняются в **Изображения → Мой Скриншот**. Папку можно сменить в **Настройках**. Формат снимков по умолчанию — PNG. В меню можно выбрать JPEG или PDF.
- Автозапуск включён по умолчанию. Его можно отключить в меню значка.

Сборка не подписана сертификатом Windows. При первом запуске Windows может показать предупреждение SmartScreen.

## Сборка

Нужен .NET 10 SDK. Из папки `Windows` выполните:

```powershell
dotnet publish MyScreenshot.Windows.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None
```

Для ARM64 замените `win-x64` на `win-arm64`.
