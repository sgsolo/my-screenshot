# Мой Скриншот

Нативное приложение для строки меню macOS 15.2 и новее. Работает на Mac с Apple Silicon и Intel.

## Возможности macOS

- **⌘⇧A** — зафиксировать кадр на дисплее под указателем. Щёлкните по подсвеченному окну, чтобы выделить его границы, или перетащите указатель, чтобы задать свою область. Края и углы рамки можно перетаскивать с любым выбранным инструментом. Чтобы передвинуть всю рамку, удерживайте **⌥ Option** и тяните её за середину.
- Панель инструментов появляется снизу. Чтобы добавить текст, введите его в поле и щёлкните по снимку. **Ластик** удаляет пометки, по которым вы проводите.
- Нажмите **Сохранить** или **Enter**, чтобы сохранить снимок. **⌘C** сохраняет снимок и копирует его в буфер обмена. Справа на пять секунд появляется миниатюра с подтверждением копирования, если снимок скопирован. При первом появлении миниатюра подскажет, что её можно перетащить в чат или другое приложение. Щелчок открывает снимок и выделяет файл в Finder. Потяните миниатюру немного вправо и отпустите, чтобы скрыть её. **Esc** закрывает редактор.
- **Скриншот экрана** — снять весь дисплей под указателем.
- **Записать область экрана** — выделить участок и нажать **Начать запись**. Пока идёт запись, экран за пределами выбранной области затемняется. **Записать весь экран** сразу запускает запись дисплея под указателем. Запись идёт без звука. Выберите **Остановить запись**, чтобы сохранить MP4. Справа на пять секунд появится миниатюра с кадром из записи. Щёлкните по ней, чтобы открыть видео и выделить файл в Finder, или перетащите её в другое приложение, чтобы вложить MP4. Свайп вправо скрывает миниатюру.
- Снимки и записи сохраняются в **Изображения → Мой Скриншот**. Другую папку можно выбрать в **Настройках**. Команда **Открыть папку сохранения** показывает текущую папку в Finder.
- В меню **Формат снимков** можно выбрать **PNG** (по умолчанию), **JPEG** или **PDF**. При выборе PDF каждый снимок сохраняется на одной странице без полей. Видео сохраняется в MP4.
- **Запускать при входе** — переключатель автозапуска. По умолчанию автозапуск включён. Если снять галочку, приложение запомнит выбор.

При первом захвате нажмите **Запросить доступ**, затем включите **Мой Скриншот** в разделе «Системные настройки → Конфиденциальность и безопасность → Запись экрана и системного звука». Если macOS предложит перезапуск, подтвердите его. Приложение сохраняет файлы локально.

## Сборка из исходников

Нужны Xcode 26 или новее и выбранные инструменты Xcode. Запустите `./build.sh` из каталога с исходниками. Скрипт соберёт универсальный пакет в `build/Мой Скриншот.app` и подпишет его локальной подписью. Для использования на своём Mac поместите пакет в папку «Программы» и откройте его.

## Сборка для публикации

Установите сертификат **Developer ID Application** с закрытым ключом в Связку ключей и один раз сохраните учётные данные для нотариализации командой `xcrun notarytool store-credentials MyScreenshot`. Введите их в интерактивном режиме.

```sh
MYSCREENSHOT_SIGNING_IDENTITY='Developer ID Application: Имя (TEAMID)' ./release.sh
```

Скрипт подпишет приложение, отправит его на нотариализацию и проверит распакованную сборку через Gatekeeper. Готовый архив для GitHub появится в `build/MyScreenshot-macOS.zip`.
