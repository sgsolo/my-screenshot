# Мой Скриншот

Делайте скриншоты, добавляйте пометки и записывайте экран. Приложение находится в строке меню macOS или в области уведомлений Windows рядом с часами.

## Установка

1. Распакуйте архив.
2. **macOS** — перенесите «Мой Скриншот» в папку «Программы» и откройте. При первом захвате разрешите приложению запись экрана в разделе «Системные настройки → Конфиденциальность и безопасность → Запись экрана и системного звука».
3. **Windows** — запустите `MyScreenshot.exe` из распакованной папки. .NET уже входит в сборку. [Подробнее об установке](Windows/README.md).

При первом запуске macOS может показать предупреждение о локальной подписи, а Windows — предупреждение SmartScreen.

## Первый скриншот

| Действие | macOS | Windows |
| --- | --- | --- |
| Открыть захват области | ⌘⇧A | Ctrl+Shift+A |
| Сохранить снимок | Enter | Enter |
| Сохранить и скопировать в буфер обмена | ⌘C | Ctrl+C |
| Отменить | Esc | Esc |

1. Щёлкните по подсвеченному окну или выделите область мышью. Границы можно подправить после выделения. Перетащите рамку с зажатой **⌥ Option** на Mac или **Alt** на Windows, чтобы переместить её целиком.
2. На панели инструментов добавьте текст, стрелки, линии или фигуры. Карандашом можно рисовать, ластиком — удалять пометки.
3. Сохраните снимок. Справа на пять секунд появится миниатюра. Щелчок открывает файл и показывает его в папке. Миниатюру можно перетащить в чат или смахнуть вправо, чтобы скрыть.

Снимок всего экрана доступен в меню значка.

## Запись экрана

В меню значка выберите **Записать область экрана** или **Записать весь экран**. При записи области экран вокруг рамки затемняется. Выберите **Остановить запись**, чтобы сохранить видео в MP4. Запись идёт без звука.

## Сохранение и настройки

- Снимки и записи сохраняются в папку **Изображения → Мой Скриншот**. Папку можно сменить в **Настройках** или открыть командой **Открыть папку сохранения**.
- В меню **Формат снимков** выберите PNG, JPEG или PDF. По умолчанию выбран PNG. PDF сохраняется на одной странице без полей.
- **Запускать при входе** включено по умолчанию. Если снять галочку, приложение запомнит выбор.

<summary>Сборка из исходников и публикация</summary>

### macOS

Нужны Xcode 26 или новее и выбранные инструменты Xcode. Запустите `./build.sh` из корня проекта. Скрипт соберёт универсальный пакет `build/Мой Скриншот.app` с локальной подписью.

Для публикации установите сертификат **Developer ID Application** с закрытым ключом в Связку ключей. Сохраните профиль нотариализации командой `xcrun notarytool store-credentials MyScreenshot` и введите учётные данные в интерактивном режиме.

```sh
MYSCREENSHOT_SIGNING_IDENTITY='Developer ID Application: Имя (TEAMID)' ./release.sh
```

Скрипт подпишет приложение, отправит его на нотариализацию и проверит распакованную сборку через Gatekeeper. Архив для GitHub появится в `build/MyScreenshot-macOS.zip`.
